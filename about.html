AboutSilen

An independent Linux distribution focused on a minimal system foundation, practical tooling, and a configurable desktop experience.

The distribution

Silen has its own ISO builder, live initramfs, installer and system integration. It is developed from source. The current system looks like this:

  • TypeIndependent distribution
  • Init (installed)OpenRC
  • Live environmentCustom BusyBox initramfs
  • KernelLinux 6.18
  • BootloaderGRUB2
  • Installation targetUEFI, x86_64
  • InstallerOnline-only, in development
  • Filesystemsext4, Btrfs

The installer is online-only, so installing requires an internet connection; the installed system does not have to stay connected. Drivers, firmware, desktop components and applications are optional additions. These details describe the system as it stands today and are not guarantees for every future edition.

The three development directions

Silen is developed in three directions. They are directions, not equally mature products, and none is available for download yet.

Silen Arch

Based on Arch Linux.

Silen Void

Based on Void Linux.

Silen Independent

The independent direction, with its own base and system tooling.

Reproducible system configurations

A Lua configuration file describes the desired system setup: packages, the desktop environment or window manager, and other supported system components. The intent is that a similar setup can be reproduced on another Silen installation.

This is not a dotfile manager. The goal is the broader system setup, not only appearance and settings. Configuration options will be documented once they exist.

In development

Package manager: cres

cres is Silen's package manager. It is being rewritten in Go, and the rewrite is in development.

  • cres get <package>install a package
  • cres find <package>search for a package
  • cres rm <package>remove a package
  • cres updateupdate the system's packages

cres link and .cress files

cres link is meant to share and reproduce system configurations. The workflow:

  1. DefineDescribe your setup in a Lua configuration.
  2. ExportUse cres link to create a file named system.cress.
  3. ShareAnother user obtains the file.
  4. Recreatecres link reads it and installs the specified packages, desktop or window manager and other supported components.

Exact syntax and supported options are not final. What can be reproduced depends on what cres link implements.

In development

Desktop direction

InstantWM is the default desktop and is intended to be the foundation of Silen's desktop experience. The base system stays minimal, and desktop components remain optional layers on top of it.

Development principles

  • SimplicityPrefer fewer moving parts to clever ones.
  • ReproducibilityMake a system describable and repeatable.
  • Practical system toolingBuild the tools the system actually needs.
  • User controlLeave decisions about the system to the person using it.
  • Independent developmentOwn the installer, builder and tooling instead of inheriting them.
