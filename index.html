Independent by design.Flexible by nature.

Silen is an independent distribution with its own build process and system tools. The installed system uses OpenRC (not systemd), iwd for Wi-Fi, and InstantWM as the default Wayland compositor. Desktop components and applications are installed via the cres package manager.

Init system

OpenRCnot systemd

The installed system uses OpenRC with elogind. The live environment boots through a custom BusyBox-based initramfs. TTYs 2–6 run agetty in both live and installed systems.

Package manager cres

Tools that belong to Silen

cres is Silen's package manager, rewritten in Go. It handles package installation, removal, search, and system updates.

Command referencecres
  1. cres get install a package
  2. cres find search for a package
  3. cres rm remove a package
  4. cres updateupdate the system's packages
In development
Lua system configuration

Describe the setup. Rebuild it elsewhere.

The goal is a Lua-based system configuration that can describe packages, desktop components, and other supported parts of a setup. The vision for cres link is to make system setups shareable and repeatable, not just a collection of dotfiles.

Illustrative Lua sketch only. The configuration format and supported options are still being developed.

Default desktop InstantWM

InstantWM is the default Wayland compositor. Rofi (mod4+Space) is the application launcher; Kitty (mod4+Return) is the default terminal. InstantMenu (mod4+E) remains available.
