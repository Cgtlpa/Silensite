Init system

OpenRCnot systemd

The installed system uses OpenRC. The live environment is separate and boots through a custom BusyBox-based initramfs.

Package manager cres

Tools that belong to Silen

cres is the package manager, currently being rewritten in Go.

Command referencecres
  1. cres get <package>install a package
  2. cres find <package>search for a package
  3. cres rm <package>remove a package
  4. cres updateupdate the system's packages
Command set in development
Lua system configuration

Describe the setup. Rebuild it elsewhere.

The goal is a Lua-based system configuration that can describe packages, desktop components, and other supported parts of a setup. The vision for cres link is to make system setups shareable and repeatable, not just a collection of dotfiles.

Illustrative Lua sketch only. The configuration format and supported options are still being developed.
